# KU Facility Service Center

เว็บ Help Desk สำหรับแจ้งงานซ่อมและบำรุงรักษาแบบ static web app ใช้ได้กับ GitHub Pages

## ฟังก์ชันหลัก

- ผู้แจ้งงานต้องใส่รหัส `123`
- บันทึกชื่อผู้แจ้ง อาคาร ชั้น อาการเสียหาย ระดับความเร่งด่วน และรูปก่อนดำเนินการ
- บันทึกอีเมลผู้แจ้งเพื่อเตรียมต่อยอดการแจ้งสถานะงาน
- สร้างรหัสแจ้งงานอัตโนมัติ เช่น `MAPM-260816-001`
- หน้าแรกแสดงจำนวนงานคงค้าง งานเสร็จแล้ว งานเร่งด่วน และงานทั้งหมด
- แสดงเปอร์เซ็นต์ความคืบหน้าและแถบ progress จากจำนวนงานที่เสร็จแล้วเทียบกับงานทั้งหมด
- เจ้าหน้าที่ปิดงานด้วยรหัส `123` พร้อมอัปโหลดรูปหลังทำและรายละเอียดงาน
- ค้นหา กรองสถานะ ส่งออก และนำเข้าข้อมูล JSON ได้
- เลือกเดือนและส่งออกรายงานการทำงานรายเดือนเป็นไฟล์ Excel `.xls`
- มีโลโก้มหาวิทยาลัยเกษตรศาสตร์จากไฟล์ `รูปตัวอย่าง/Logo_ku_th.svg.webp`
- แสดงสถานะพื้นที่จัดเก็บข้อมูล 100 MB และล้างงานเก่าอัตโนมัติเมื่อเกินกำหนด
- มี Activity Log สำหรับการแจ้งงาน เริ่มดำเนินงาน ปิดงาน ยกเลิกงาน และนำเข้าข้อมูล
- เจ้าหน้าที่กดเริ่มดำเนินงานได้ด้วยรหัส `123` และระบบแสดงสถานะ `แจ้งงาน` / `กำลังดำเนินงาน`
- แสดงกราฟเปรียบเทียบงานรายเดือนและรายปี
- มี animation SVG รวมสำหรับงานท่อน้ำ ไฟฟ้า และแสงสว่างใน header
- มีปุ่มเปลี่ยนภาษาไทย/อังกฤษด้วยรูปธงชาติ

## วิธีเปิดใช้งาน

เปิดไฟล์ `index.html` ใน browser ได้ทันที หรืออัปโหลดทั้งโฟลเดอร์นี้ขึ้น GitHub แล้วเปิด GitHub Pages

## หมายเหตุ

เวอร์ชันนี้เก็บข้อมูลใน browser ด้วย `localStorage` จึงเหมาะกับการทดลองหรือใช้งานเครื่องเดียว หากต้องการใช้งานหลายคนพร้อมกันควรเพิ่ม backend หรือเชื่อม GitHub Issues / GitHub API สำหรับเก็บงานส่วนกลาง
